BRUTA X architecture notes

2026-11-03

When building BRUTA X, UI code stays in app/ui, pure assessment logic in app/modules, and cross-cutting concerns (jobs, RBAC, correlation) in app/services. That split keeps PySide6 views from owning network policy. Authorization is enforced in module entry points and workflows — a checkbox in the UI is not enough by itself; the backend must refuse unauthorized active checks. Correlation only creates graph edges from concrete evidence fields (DNS answers, cert CN, finding IDs), never from guesses.
